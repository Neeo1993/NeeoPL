# NeeoP&L

Домашний учёт доходов, расходов и накоплений. Считает план и факт по месяцам,
показывает сальдо, копит резервы и рисует диаграмму куда ушло по факту.

## Что умеет

Учёт ведётся по периодам -- месяц и год задаются вручную, история не удаляется.
Внутри каждого периода три раздела: доходы, накопления и расходы.

**Доходы.** Можно добавить сколько угодно строк -- зарплата, подработка, разовые
поступления. Каждую потом можно отредактировать или удалить. Есть кнопка
"Залезть в накопления" -- переносит сумму из общего накопленного резерва всех
периодов в доход текущего и одновременно фиксирует минусовую запись в
накоплениях, чтобы баланс сошёлся.

**Накопления.** Тоже список записей -- можно копить под разные цели. Сумма
накоплений текущего периода вычитается из сальдо, поэтому видно реальную
свободную сумму. Накопления можно редактировать и удалять.

**Расходы.** Каждая статья имеет план и факт. Факт можно вводить не сразу --
поля факта и сальдо остаются пустыми, пока не появятся данные. У статьи есть
чекбокс "Завершена" -- после отметки строка сереет и блокирует редактирование.
Прибавить к факту можно отдельно кнопкой с плюсом, не перезаписывая предыдущее
значение. Названия статей запоминаются как шаблоны -- в следующих периодах они
подсказываются в поле ввода с автоподстановкой плановой суммы.

**Диаграмма.** Рядом со списком расходов рисуется круговая диаграмма по
категориям (по факту). Клик по элементу легенды скрывает категорию, диаграмма
перестраивается на лету. Цвета закреплены за категориями и не прыгают. Дополнительно
двумя секторами показываются сбережения и иные расходы (сальдо).

**Сводка по периоду.** Два ряда виджетов: доходы / накопления / расходы и
сальдо (план) / сальдо (факт). Сальдо считается как доход минус расход минус
накопления.

**Сводка по всем периодам.** На главной -- суммарные доходы, расходы и
накопления по всем периодам сразу.

**Настройки.** Можно сменить валюту (рубль, доллар, евро, тенге, турецкая лира)
и указать путь к файлу базы данных -- например, в папку iCloud для
синхронизации между устройствами. При смене пути текущая база копируется в
новое место. Все суммы в интерфейсе переключаются на выбранную валюту.

**Авторизация.** При первом запуске предлагается создать логин и пароль
администратора. Все страницы закрыты для неавторизованных. Кука сессии живёт
30 дней, повторный вход не требуется. Кнопка "Выйти" -- в шапке. Документация
API (/docs, /redoc) отключена. Если пароль забыт -- сбрасывается из терминала
(см. ниже).

## Стек

Python 3.14, FastAPI, SQLAlchemy, SQLite. Фронтенд -- Jinja2-шаблоны, HTMX для
обновления без перезагрузки страницы, Tailwind CSS через CDN, Chart.js для
диаграммы. Сборки JS нет, всё работает из коробки. Зависимости -- bcrypt,
itsdangerous, python-multipart.

## Развертывание

Везде нужен Python 3.14 и менеджер пакетов uv. uv ставит изолированное
окружение сам, отдельно venv создавать не надо.

### Установка uv

**macOS / Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows (PowerShell):**
```powershell
irm https://astral.sh/uv/install.ps1 | iex
```

После установки перезапустите терминал или выполните `source ~/.cargo/env`
(macOS/Linux), чтобы uv появился в PATH.

### Запуск проекта

Перейдите в папку проекта и выполните:
```bash
uv run neeopl
```

uv сам скачает Python нужной версии, поставит зависимости из uv.lock и
запустит сервер. Откройте http://127.0.0.1:8000 -- при первом входе
попросит создать администратора.

Порт по умолчанию -- 8000. Чтобы сменить:
```bash
uv run uvicorn neeopl.app:create_app --factory --port 9000
```

### Автозапуск при загрузке системы

В папке `scripts/` есть скрипты, которые делают всё сами: ставят uv, ставят
зависимости, создают папку data и регистрируют службу в автозапуске. Запускать
из папки проекта.

**macOS:**
```bash
bash scripts/install-macos.sh
```
Создаёт launchd-агента `ai.neeopl.server` (KeepAlive, запуск при входе).
Управление:
```bash
launchctl unload ~/Library/LaunchAgents/ai.neeopl.server.plist   # остановить
launchctl load ~/Library/LaunchAgents/ai.neeopl.server.plist     # запустить
tail -f data/neeopl-server.log                                    # логи
```

**Linux:**
```bash
bash scripts/install-linux.sh
```
Создаёт пользовательскую службу systemd `neeopl` и включает enable-linger,
чтобы служба работала без логина. Управление:
```bash
systemctl --user stop neeopl      # остановить
systemctl --user start neeopl     # запустить
systemctl --user status neeopl    # статус
journalctl --user -u neeopl -f    # логи
```

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-windows.ps1
```
Создаёт задачу "NeeoPL" в планировщике задач (запуск при входе, авто-рестарт).
Управление:
```powershell
Stop-ScheduledTask -TaskName "NeeoPL"                       # остановить
Start-ScheduledTask -TaskName "NeeoPL"                      # запустить
Get-ScheduledTask -TaskName "NeeoPL"                        # статус
Unregister-ScheduledTask -TaskName "NeeoPL" -Confirm:$false # удалить
```

## Сброс пароля

Если пароль администратора забыт, из папки проекта:
```bash
uv run python -m neeopl.reset_password admin новый_пароль
```

Или интерактивно (попросит логин и пароль с подтверждением):
```bash
uv run python -m neeopl.reset_password
```

После сброса перезапускать сервер не обязательно -- новый пароль работает сразу.

## База данных

Один файл SQLite, по умолчанию `data/neeopl.db`. Путь можно сменить в
настройках приложения -- база скопируется в новое место. Конфиг (путь к БД,
валюта, ключ подписи куки) лежит в `data/config.json`.
